# Security Policy

This repository is a clean review package for an OKX Agentic Wallet competition Skill.

## Safety Boundary

- No private keys, seed phrases, mnemonics, or wallet export flows.
- No Telegram bot token, API key, or private credential should be committed.
- The v1 Skill is paper-first and does not sign, broadcast, or execute live swaps.
- Operator-in-the-loop live evidence is documentation only; the user manually confirms Agentic Wallet trades.

## Reporting Issues

If you find accidental credential exposure or an unsafe execution path, open a private security report or contact the repository owner directly. Do not post secrets in public issues.
